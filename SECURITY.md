## How to report

Contact **privately** — do not open a public issue.

| Channel | |
|:--------|:--|
| Discord | **nandak070** (`1219803151180370021`) |
| GitHub | [nanda070](https://github.com/nanda070) — private advisory if available |

**Subject:** `[SECURITY] QuestMaster — <short summary>`

### Include

- What is wrong and what impact it has  
- Minimal reproduction steps  
- Environment (OS, Discord / Vencord version)  
- Logs or screenshots with secrets redacted  
- Whether it reproduces reliably  

### Do not

- Open public GitHub issues for security findings  
- Publish exploits or abuse write-ups  
- Send tokens, cookies, or personal data  

---

## Timeline

Valid reports are usually acknowledged within **7 days**. If confirmed, a fix and disclosure plan are coordinated when possible. Timing depends on severity and availability.

---

## Scope

Examples of in-scope reports:

- Supply-chain risks or suspicious scripts  
- Credential / sensitive data leakage  
- RCE, privilege escalation, command injection  
- Behavior that enables abuse beyond documented intent  

---

## Safe harbor

Good-faith research and responsible disclosure are welcome. Do not harm users, violate privacy, or disrupt services.
